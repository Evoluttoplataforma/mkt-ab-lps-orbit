10. FAQ — quebra de objeção
Headline: Perguntas frequentes
Q1. Funciona para empresa que nunca documentou processo?
Sim — é exatamente o ICP. O agente IA acelera muito a primeira documentação.
Q2. Substitui consultoria ISO?
Acelera a consultoria. A documentação que tradicionalmente leva meses fica pronta em semanas. Consultoria foca em treinamento e auditoria final.
Q3. Posso usar BPMN avançado?
Sim. O editor suporta BPMN 2.0 completo (gateways, sub-processos, pools, lanes). O agente IA gera o básico — você refina.
Q4. E processos não documentáveis (criativos)?
BPM brilha em processos repetíveis. Para processos criativos, o módulo Projetos (com Gantt/Kanban) é melhor. Vários clientes usam os dois.
Q5. Integra com ERP atual?
Sim, via API REST. Cada processo pode disparar ação no ERP (ex: criar pedido no TOTVS quando aprovação OK no Orbit).
Q6. Quanto custa?
Faixa típica do ICP: R$ 1.500 a R$ 4.500/mês para a plataforma toda (Processos incluído). Fale com a Olívia para estimativa exata.
