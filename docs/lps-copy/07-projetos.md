10. FAQ — quebra de objeção
Headline: Perguntas frequentes
Q1. Migra do Asana / Monday / Trello?
Sim. Importação guiada de projetos, tarefas, responsáveis e histórico. Sem perder dado.
Q2. Tem Gantt de verdade (com dependências)?
Sim. Gantt com dependências, caminho crítico, baseline e replanejamento.
Q3. Funciona para projeto ágil (Scrum/Kanban)?
Sim. Kanban nativo com WIP limits, sprints configuráveis e gráficos burndown/burn-up.
Q4. Posso conectar com ferramentas externas (GitHub, Figma)?
Sim, via API REST e webhooks. Vários clientes têm Orbit + GitHub + Figma + Slack integrados.
Q5. Quem usa? Só PMO?
PMO planeja. Gestores acompanham. Colaboradores executam tarefas. Diretoria vê painel executivo. Tudo na mesma plataforma.
Q6. Quanto custa?
Faixa típica do ICP: R$ 1.500 a R$ 4.500/mês para a plataforma toda (Projetos incluído). Fale com a Olívia para estimativa exata.
