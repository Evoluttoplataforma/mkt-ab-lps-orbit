10. FAQ — quebra de objeção
Headline: Perguntas frequentes
Q1. Substitui a folha de pagamento?
Não. Orbit Pessoas integra com sistema de folha (Mywork, Solides, Senior, etc) via API. Foco é gestão de pessoas, não cálculo da folha.
Q2. Funciona com a Gupy/Kenoby que já uso?
Sim — mas a longo prazo, a maioria dos clientes migra o ATS para o Orbit pela integração nativa. Suportamos integração intermediária.
Q3. É só ATS ou tem onboarding também?
ATS + onboarding + PDI + trilhas + organograma + pesquisa de clima. Tudo conectado.
Q4. Posso integrar com plataforma de assinatura eletrônica?
Sim. Integração com DocuSign, ClickSign, ZapSign para envio de contratos pós-contratação.
Q5. E LGPD?
Conformidade LGPD nativa. Consentimento, anonimização, exclusão sob demanda, trilha de auditoria de acesso a dados sensíveis.
Q6. Quanto custa?
Faixa típica do ICP: R$ 1.500 a R$ 4.500/mês para a plataforma toda (Pessoas incluído). Fale com a Olívia para estimativa exata.
