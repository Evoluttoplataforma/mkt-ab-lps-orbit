10. FAQ — quebra de objeção
Headline: Perguntas frequentes
Q1. Funciona para empresa que ainda não tem BSC implantado?
Sim. A implantação inclui workshop conduzido pela Orbit para construir o BSC junto com sócios.
Q2. É só BSC ou inclui OKR?
Os dois. BSC para visão anual/estratégica, OKR para execução trimestral. Os dois conversam.
Q3. Como funciona a análise de concorrência por IA?
Agente coleta dados públicos (LinkedIn, sites, notícias, reviews) dos concorrentes que você listar. Atualiza o painel mensalmente. Você revisa.
Q4. Posso usar para preparar auditoria ISO?
Sim. SWOT, política, escopo, partes interessadas, objetivos do sistema e versionamento atendem exatamente os requisitos ISO 9001:2015.
Q5. Quem usa? Só diretoria?
Diretoria edita estratégia. Gestores intermediários veem objetivos da sua área. Colaboradores veem tarefas conectadas a OKRs — todos veem o 'porquê' do trabalho.
Q6. Quanto custa?
Faixa típica do ICP: R$ 1.500 a R$ 4.500/mês para a plataforma toda. Inclui Estratégico, Indicadores, Processos e os demais módulos. Fale com a Olívia para estimativa exata.
