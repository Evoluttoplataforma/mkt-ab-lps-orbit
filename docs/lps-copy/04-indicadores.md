10. FAQ — quebra de objeção
Headline: Perguntas frequentes
Q1. Posso conectar Google Sheets externos?
Sim. Conectores nativos para Google Sheets, CSV, planilha Excel e API REST.
Q2. Funciona como Power BI?
Para uso executivo, sim — e melhor, porque vem pré-configurado para empresa média B2B. Para análise estatística avançada, Power BI ainda tem mais profundidade. Vários clientes usam os dois (Orbit para execução, Power BI para análise ad-hoc).
Q3. Posso compartilhar dashboard por e-mail?
Sim. Snapshot semanal/mensal automático para diretoria por e-mail.
Q4. Tem mobile?
Sim. App nativo iOS/Android com os dashboards executivos.
Q5. Quem usa?
Diretoria vê painel executivo. Gerentes veem painel da sua área. Colaborador vê KPI individual conectado ao OKR.
